# GELP 2026 Campus Food Rescue

This repository is related to the GELP 2026 project focused on reducing campus food waste and improving student food security in the Prairies.

## Project Link

[GELP 2026: Bridging Campus Food Waste Reduction and Student Food Security in the Prairies](https://northamericacampusfoodrescue.notion.site/GELP-2026-Bridging-Campus-Food-Waste-Reduction-and-Student-Food-Security-in-the-Prairies-2faae672f1a080848b3cfd571db1f755)

## Project Focus

The project explores how campus food rescue initiatives can help reduce food waste while supporting students experiencing food insecurity.
